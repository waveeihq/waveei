# Contributing

Bug reports are welcome as GitHub issues: what you did, what you expected, what happened, your phone and Android
version, and, if you can, the app's log (Feedback in the app with Attach the event log on; it holds no dictated text).

Pull requests are not accepted for now. The code is source-available under FSL-1.1-ALv2 (see `LICENSE.md`), and
accepting outside code would need a contributor agreement that does not exist yet.
