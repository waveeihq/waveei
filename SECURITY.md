# Security

Please report a vulnerability privately, not in a public issue: use GitHub's
[private vulnerability reporting](../../security/advisories/new) on this repository.

Say what you found, how to reproduce it, and what it lets someone do. We answer within 7 days and tell you when a fix
ships. Research done in good faith, that stays within your own account and data and stops at proof of the problem,
will not be met with legal action from us.

Only the latest release is supported.
